An autonomous agent that plans the investigation, gathers cited evidence, runs its own analyses in a sandbox, judges with a calibrated model, reviews its own verdict adversarially, and designs the experiment that would settle the variant — or declines, honestly, when the evidence is too thin. Not for clinical use.

Research project only — not for clinical use. Evidence summaries are not clinical classifications.

Temporal integrity: only prediction-time records (ClinVar frozen 2024-01) are used as evidence; later reclassifications are never loaded. This demo runs in the offline benchmark configuration — deterministic local data, no LLM, no live gatherers. Distribution graphs are computed from the bundled temporal test set itself.
